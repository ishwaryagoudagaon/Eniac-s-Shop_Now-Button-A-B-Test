# Dataset

This folder contains the datasets used for Eniac's A/B testing experiment.

## Files

| File | Description |
|---|---|
| `eniac_A.csv` | Data for Version A – White "SHOP NOW" |
| `eniac_B.csv` | Data for Version B – Red "SHOP NOW" |
| `eniac_C.csv` | Data for Version C – White "SEE DEALS" |
| `eniac_D.csv` | Data for Version D – Red "SEE DEALS" |
